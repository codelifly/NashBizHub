# Customer-side scope from business proposal

Source: `NashBizHub_Business_Platform_Proposal.docx` (extracted 24 Oct 2026).

## Navigation (implemented)

Customer language: Buy a Business, Sell a Business, Rent a Business, Contracts, Find a Broker, Resources, plus Post an Opportunity, Sign in / Register / Log out.

Added from proposal pass (Oct 2026): `/contracts` hub, `/glossary`, `/tours` (local demo video), `/dashboard/maintenance`, prominent **Back to home** on Demo Center + customer/admin shells.

## Opportunity types

Sale · operating rental · premises lease · management contract · service tender · buyer/operator requirements.

## Customer account capabilities

- Register / verify / sign in / recover password / sign out
- Role-flexible interests (buy, sell, rent, operate, contract)
- Favorites, saved searches, compare shortlist
- Inquiries, messages, appointments, offers, applications
- Listing wizard (customer-owned drafts)
- Agreements, obligations, maintenance reporting
- Profile, verification, security, support, membership (demo)

## Explicitly out of this customer redesign pass

Staff CRM, admin moderation UIs, Laravel PHP backend (proposal appendix). This demo remains Next.js + TypeScript with a clean API boundary for a later Laravel connection.

## Technology note from proposal vs this demo

Proposal appendix suggests React + Laravel PHP. The Cursor master prompt for this interactive demo supersedes that with Next.js. Customer UX and features still follow the proposal’s business language and journeys.
